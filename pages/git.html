Introduction à Git

Git a été créé en 2005 par Linus Torvalds, le fondateur du noyau Linux. Il a développé cette technologie afin de répondre aux besoins de rapidité, de décentralisation et de fiabilité requis pour coordonner le travail de milliers de contributeurs à travers le globe.

L'objectif de Git est de suivre l'historique d'un ensemble de fichiers de code source. Il permet de sauvegarder l'évolution d'un projet, de revenir à des versions antérieures en cas de bug et de fusionner proprement les développements écrits en parallèle par différents membres d'une équipe.

C'est un système de gestion de version décentralisé (VCS). Chaque développeur possède une copie locale intégrale de l'historique sur sa machine, lui permettant de travailler de manière autonome sans connexion.

Les commandes Git fondamentales

Le workflow standard local repose sur quelques instructions simples à taper dans le terminal :

  • git init : crée un nouveau dépôt Git local au sein du répertoire courant
  • git status : liste les fichiers modifiés ou créés qui ne sont pas encore sauvegardés
  • git add : prépare et bascule les fichiers modifiés dans la zone de transit (Staging Area)
  • git commit -m : valide et fige définitivement l'état des fichiers préparés dans l'historique

Le système de branches

Les branches permettent d'isoler des espaces de travail indépendants pour développer des fonctionnalités :

  • git branch : répertorie les branches existantes ou crée une nouvelle ligne de code
  • git checkout / switch : permet de basculer d'une branche de travail à une autre
  • git merge : fusionne l'historique et les modifications d'une branche dans la branche active

Exemple de workflow Git

            
                # Cloner un dépôt existant et enregistrer des modifications
                git clone https://example.com
                cd depot
                
                # Modification des fichiers du projet
                git add html.html style.css
                git commit -m "Mise à jour des contenus pédagogiques"
                git status
