Introduction à GitHub

GitHub a été lancé en 2008 par Chris Wanstrath, P. J. Hyett et Tom Preston-Werner. Développé pour centraliser le partage de code, le service a été racheté par Microsoft en 2018 pour devenir la plus grande plateforme de développement collaboratif au monde.

GitHub a été conçu pour héberger des dépôts Git dans le cloud. Son but est de fournir une interface graphique intuitive en ligne, facilitant la collaboration à distance, le suivi des correctifs de bugs, la relecture de code par les pairs et l'automatisation des déploiements.

La plateforme combine les fonctionnalités techniques de Git avec des outils de gestion de projet et d'aspects communautaires, jouant le rôle de réseau social mondial pour les développeurs.

Synchronisation Git et GitHub

Pour lier votre machine locale à l'hébergement cloud, on utilise des commandes réseau dédiées :

  • git remote add origin : associe votre dossier Git local à un dépôt distant sur GitHub
  • git push : téléverse l'ensemble de vos commits locaux vers les serveurs en ligne de GitHub
  • git pull : télécharge et fusionne les derniers commits distants sur votre machine locale

Fonctionnalités collaboratives clés

GitHub enrichit le gestionnaire Git d'outils visuels facilitant le suivi des projets en équipe :

  • Pull Requests (PR) : mécanisme formel pour proposer des modifications de code à valider
  • Issues : système de tickets pour répertorier les bugs, tâches et suggestions d'amélioration
  • GitHub Pages : service gratuit permettant d'héberger des sites statiques (HTML/CSS) directement

Exemple de commandes GitHub

            
                # Associer son projet local et envoyer le code vers GitHub
                git remote add origin https://github.com
                
                # Configurer la branche principale locale
                git branch -M main
                
                # Pousser les modifications locales sur le serveur cloud
                git push -u origin main
