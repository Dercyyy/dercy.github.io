Introduction à SQL

SQL (Structured Query Language) a été initialement développé par les chercheurs d'IBM au début des années 1970 sur la base du modèle relationnel de données. Il est devenu le standard officiel de gestion de données en 1986.

Le but de SQL est d'offrir un langage normalisé pour interagir avec des bases de données relationnelles. Il permet aux administrateurs et développeurs de structurer des tables, d'insérer, de mettre à jour, de sécuriser et d'extraire efficacement des données volumineuses.

SQL est un langage déclaratif. L'utilisateur indique au système le résultat qu'il souhaite obtenir (quelles données extraire), et le moteur de base de données se charge de déterminer la méthode d'exécution.

Les types de requêtes SQL

Les instructions SQL se répartissent en plusieurs sous-ensembles selon la nature de l'opération effectuée sur la base :

  • SELECT : commande d'extraction permettant d'interroger et de lire les enregistrements
  • INSERT / UPDATE / DELETE : commandes de manipulation pour ajouter, modifier ou purger des lignes
  • CREATE / ALTER / DROP : requêtes de définition pour bâtir ou détruire des structures de tables
  • JOIN : clauses d'association croisant les informations réparties sur plusieurs tables

Clauses de filtrage courantes

Pour trier et isoler précisément les informations, les requêtes s'associent à des mots-clés restrictifs :

  • WHERE : applique une ou plusieurs conditions strictes pour filtrer les lignes de données
  • ORDER BY : organise l'affichage des résultats par ordre croissant (ASC) ou décroissant (DESC)
  • GROUP BY : rassemble les lignes identiques pour réaliser des calculs d'agrégation (somme, moyenne)

Exemple de code SQL

            
                -- Sélectionner les étudiants de la filière SIO
                SELECT id_etudiant, nom, prenom 
                FROM t_etudiants
                WHERE section = 'SIO'
                ORDER BY nom ASC;
                
                -- Insérer un nouvel enregistrement dans la table
                INSERT INTO t_etudiants (nom, prenom, section) 
                VALUES ('Dupont', 'Jean', 'SIO');
