Aide-Mémoire : Les Commandes Linux

Linux est un système d'exploitation puissant entièrement pilotable en ligne de commande. Le terminal permet d'exécuter des tâches complexes, de gérer des fichiers et d'administrer un système avec rapidité et précision.

Cet aide-mémoire regroupe les commandes indispensables pour naviguer dans l'arborescence, manipuler les fichiers, vérifier l'état du système et gérer les permissions.

Chaque commande s'exécute en tapant son nom dans le terminal, souvent accompagnée d'arguments ou d'options (comme -l ou -h) pour modifier son comportement par défaut.

Navigation & Fichiers

Ces commandes de base permettent de vous repérer dans l'arborescence Linux et de lister les éléments présents :

  • pwd : affiche le chemin complet du dossier courant
  • ls -la : liste tous les fichiers, y compris les fichiers cachés, avec leurs détails
  • cd /chemin/ : change de répertoire pour aller vers la destination spécifiée
  • mkdir nom_dossier : crée un nouveau répertoire vide

Manipulation de fichiers

Utilisez ces commandes pour créer, copier, déplacer ou supprimer vos documents et dossiers :

  • touch fichier.txt : crée un fichier vide ou met à jour sa date de modification
  • cp source.txt dest.txt : copie un fichier (ajoutez -r pour copier un dossier entier)
  • mv ancien_nom nouveau_nom : déplace ou renomme un fichier ou un dossier
  • rm -rf nom_dossier : supprime définitivement et sans confirmation un dossier et son contenu

Gestion du système & Droits

Ces outils servent à surveiller les ressources de la machine et à gérer les privilèges de sécurité :

  • sudo commande : exécute la commande avec les privilèges de l'administrateur (root)
  • chmod 755 fichier : modifie les permissions d'accès (lecture, écriture, exécution)
  • top : affiche en temps réel les processus actifs et l'utilisation de la mémoire/CPU
  • df -h : montre l'espace disque disponible sur les différentes partitions

Exemple de script Linux (Bash)

            
                #!/bin/bash
                echo "Début du script de sauvegarde..."
                mkdir -p /home/user/sauvegarde
                cp -r /var/www/html /home/user/sauvegarde/
                echo "Sauvegarde terminée avec succès !"
