Introduction à PHP

PHP (Hypertext Preprocessor) a été créé par Rasmus Lerdorf en 1994. Conçu initialement pour suivre les visites sur son site web personnel, il s'est transformé en un puissant langage de script open-source utilisé dans le monde entier.

PHP a été conçu dans le but de générer dynamiquement des pages web côté serveur. Il permet de récupérer des informations issues de formulaires, de gérer des sessions utilisateur sécurisées et de communiquer de manière transparente avec des bases de données avant d'envoyer le HTML final au client.

C'est un langage exécuté sur le serveur, ce qui signifie que le client ne voit jamais le code PHP d'origine, mais seulement le résultat produit sous forme de code HTML ou de fichiers multimédias.

Les fondamentaux de PHP

Le code PHP s'intègre directement au milieu du code HTML et utilise des structures spécifiques pour traiter les données :

  • <?php et ?> : balises d'ouverture et de fermeture délimitant le code serveur
  • $ (symbole dollar) : préfixe obligatoire pour déclarer et utiliser une variable
  • echo : instruction principale permettant d'afficher du texte ou d'injecter du HTML
  • include / require : instructions pour importer et modulariser des fichiers externes

Superglobales PHP courantes

Les superglobales sont des tableaux natifs accessibles partout dans le script pour récupérer l'état du système :

  • $_POST : récupère les données envoyées via la méthode POST d'un formulaire
  • $_GET : extrait les variables passées directement dans l'URL de la page
  • $_SESSION : conserve les variables de l'utilisateur tout au long de sa navigation
  • $_SERVER : contient des informations sur les en-têtes, les dossiers et les scripts

Exemple de code PHP

            
                <?php
                // Déclaration de variables et structure conditionnelle
                $heure = date("H");
                
                if ($heure < 18) {
                    echo "<p>Bonjour et bienvenue sur notre application web !</p>";
                } else {
                    echo "<p>Bonsoir et bienvenue sur notre application web !</p>";
                }
                ?>
