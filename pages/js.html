Introduction à JavaScript

JavaScript a été créé par Brendan Eich en 1995 pour le navigateur Netscape. Conçu à l'origine en seulement dix jours, il s'est rapidement imposé comme la technologie incontournable pour rendre les pages web dynamiques et interactives.

L'objectif de JavaScript est de manipuler le contenu d'une page en réponse aux actions des utilisateurs. Avec l'arrivée de Node.js, il permet désormais de développer des applications complètes, aussi bien du côté client (navigateur) que du côté serveur.

JavaScript est un langage de script orienté objet, à typage dynamique et léger, standardisé sous le nom d'ECMAScript. Il est interprété nativement par tous les navigateurs web modernes.

Les concepts clés de JavaScript

Le langage repose sur des structures fondamentales pour stocker des données et contrôler la logique de l'application :

  • let / const : mots-clés utilisés pour déclarer des variables et des constantes
  • function : bloc de code réutilisable destiné à exécuter une tâche précise
  • Le DOM (Document Object Model) : structure permettant à JavaScript de modifier le HTML
  • addEventListener : méthode pour écouter et réagir aux événements (clics, surpoids)

Types de données courants

JavaScript manipule différents types de valeurs fondamentales selon la nature de l'information stockée :

  • String : chaînes de caractères entourées de guillemets simples ou doubles
  • Number : valeurs numériques, gérant à la fois les entiers et les décimaux
  • Boolean : valeurs logiques représentant uniquement vrai (true) ou faux (false)
  • Array / Object : structures complexes pour regrouper des listes ou des entités
