Introduction à Angular

Angular est un framework applicatif open-source développé et maintenu par les équipes de Google. Conçu comme une refonte intégrale de l'ancien AngularJS, sa première version stable est sortie en 2016.

L'objectif d'Angular est de fournir une plateforme complète pour structurer des Single Page Applications (SPA) côté client. Il permet de synchroniser l'affichage avec la logique métier, mettant à jour dynamiquement l'interface sans jamais nécessiter de rechargement complet de la page.

Le framework impose l'utilisation de TypeScript. Son architecture stricte et hautement modulaire est particulièrement adaptée pour le développement d'applications web complexes à l'échelle industrielle.

L'architecture d'Angular

Une application Angular s'articule autour de concepts modulaires interdépendants :

  • Composants (Components) : blocs de base liant une vue HTML, du style CSS et du code logique
  • Gabarits (Templates) : code HTML enrichi de directives propres pour afficher les données
  • Directives (*ngIf, *ngFor) : attributs logiques permettant de manipuler la structure HTML
  • Services : classes dédiées à la centralisation et au partage des données entre composants

Outils intégrés au Framework

Angular intègre nativement toutes les briques nécessaires sans dépendre de packages externes :

  • Angular CLI : interface en ligne de commande pour générer et compiler l'application
  • Le Routeur : module gérant la navigation fluide entre les différentes vues de l'application
  • Client HTTP : couche optimisée pour interagir avec des API et services backend distants

Exemple de code Angular

            
                import { Component } from '@angular/core';

                @Component({
                  selector: 'app-bienvenue',
                  template: `<h1>Bonjour {{ etudiant }} !</h1>`,
                  styles: [`h1 { color: #dd0031; }`]
                })
                export class BienvenueComponent {
                  etudiant: string = 'Étudiant SIO';
                }
